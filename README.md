# Python lab 7
____
## Условие задачи:
### Задание 7.
Реализовать интерактивный калькулятор в вещественных числах, поддерживающий следующие операции:
- Сложение, умножение, вычитание, деление, степень.
- Скобки.
- Унарный минус.
- Операцию взятия предыдущего результата `_`.

Также калькулятор должен:
- Учитывать естественную очередность операций.
- Поддерживать числа `inf`, `+inf`, `-inf`, `nan`.
- Корректно обрабатывать деление на ноль и операции с бесконечностями.

Пользоваться `eval` нельзя.
____
## Описание решения
____
- `calculator.py` — класс `Calculator`, `main.py` — интерактивный цикл и настройка логирования.
- Выражение сначала разбивается на токены регулярным выражением, затем вычисляется методом рекурсивного спуска.
- Приоритет операций (от низшего к высшему): `+` и `-`, затем `*` и `/`, затем унарные `+` и `-`, затем степень `^` (можно писать `**`).
  - Унарный минус слабее степени: `-2^2 = -4`.
  - Степень правоассоциативна: `2^3^2 = 2^(3^2) = 512`.
  - Показатель степени может быть со знаком: `2^-1 = 0.5`.
- `inf` и `nan` вводятся в любом регистре (`INF`, `NaN`).
- `_` — результат последнего успешно вычисленного выражения (в начале `0.0`). Если в выражении ошибка, `_` не меняется.
- Особые случаи не вызывают исключений, результатом становится `nan` или `inf`, а в консоль выводится предупреждение:

| Выражение | Результат |
|---|---|
| `0/0`, `1/0`, `-1/0` | `nan` |
| `inf - inf`, `inf * 0` | `nan` |
| `0 ^ -1` | `inf` |
| `10 ^ 400` (переполнение) | `inf` |
| `(-10) ^ 401` (переполнение) | `-inf` |
| `(-8) ^ (1/3)` (отрицательное число в дробной степени) | `nan` |

- Синтаксические ошибки (недопустимый символ, незакрытая или лишняя скобка, оборванное выражение, слишком глубокая вложенность) выводятся как `Ошибка: ...`, после чего можно ввести следующее выражение.
- Все действия пишутся в файл `calculator.log` в текущей папке. В консоль по умолчанию выводятся только предупреждения, с ключом `-v` — все сообщения.

| Метод `Calculator` | Описание |
|---|---|
| `calculate(expression)` | Вычисляет строку-выражение, возвращает `float` и запоминает его как `_` |
| `tokenize(expression)` | Разбивает строку на токены |
| `parse_expr`, `parse_term`, `parse_unary`, `parse_power`, `parse_atom` | Уровни рекурсивного спуска: сумма, произведение, унарный знак, степень, число/скобки |
| `power(base, exponent)` | Возведение в степень с обработкой особых случаев |

## Установка виртуального окружения и запуск
____
### 1. Клонируйте репозиторий
```bash
git clone https://github.com/Syntax-Error-Squad/task-7-calculator.git
cd task-7-calculator
```
### 2. Создайте виртуальное окружение
```bash
python -m venv venv
```
### 3. Активируйте виртуальное окружение
- **Windows CMD**
```bash
.\venv\Scripts\activate
```
- **Windows PowerShell**
```powershell
.\venv\Scripts\Activate.ps1
```
- **macOS/Linux**
```bash
source venv/bin/activate
```
После активации виртуального окружения в командной строке появится префикс venv.
### 4. Запустите программу
```bash
python main.py
```
С подробными логами в консоли:
```bash
python main.py -v
```
Для выхода введите `exit`, `quit` или `q`.

### Использование в своём коде
```python
from calculator import Calculator

calc = Calculator()
print(calc.calculate("2 + 3 * 4"))   # 14.0
print(calc.calculate("_ ^ 2"))       # 196.0
print(calc.calculate("inf * 0"))     # nan
```
